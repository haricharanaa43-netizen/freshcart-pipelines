# FreshCart Pipelines

An end-to-end Data Engineering project covering Git, CI/CD, ELT, Machine Learning pipelines, and real-time event streaming.

## Project Structure

- `elt/` – FreshCart ELT pipeline using Snowflake.
- `iris_project/` – Machine Learning pipeline using Mage.
- `stream/` – Real-time food-order streaming using RabbitMQ.
- `tests/` – Automated tests using pytest.
- `.github/workflows/` – GitHub Actions CI workflow.

## Technologies

- Python
- Git and GitHub
- Snowflake
- Mage
- RabbitMQ
- Scikit-learn
- Pytest
